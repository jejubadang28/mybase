# 구글 드라이브 연결

연결하면 드라이브의 `MY BASE` 폴더에 저장돼요.

- 자료실·발표에 올린 파일 (`MY BASE/자료실`, `MY BASE/발표`). 한 파일 30MB까지. 더 큰 파일은 드라이브 앱으로 그 폴더에 넣으면 사이트에도 보여요.
- 메모·할 일·일정·자주 가는 사이트 (`MY BASE/기록/data.json`). 핸드폰과 컴퓨터에서 같이 보여요.
- 다른 사람이 '파일 받기 링크'로 보낸 파일 (`MY BASE/받은 파일`). 자료실 맨 위에 '받음'으로 떠요. 자료실의 '파일 받기 링크'에서 링크를 복사하거나 바꿀 수 있어요.
- 아침 읽기에서 푼 기록 (`MY BASE/MY BASE 읽기 기록/readmarks-날짜.json`). 아침 작업이 읽어서 단어장에 반영해요.

## 순서 (컴퓨터에서 하는 게 편해요)

1. 드라이브로 쓸 구글 계정으로 https://script.google.com 에 들어가 **새 프로젝트**를 만들어요. 학교 계정은 4번에서 '모든 사용자'를 고를 수 없을 수 있어서 개인 계정(gmail)이 좋아요.
2. 원래 있던 코드를 모두 지우고 `Code.gs` 내용을 붙여 넣어요. 맨 위 `KEY` 에 16자 이상 아무 글자나 넣고 저장해요.
3. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행**을 눌러요. 권한을 물으면 허용해요.
   "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동**을 눌러요. 내가 만든 코드라 괜찮아요.
4. **배포 → 새 배포 → 유형: 웹 앱** 을 고르고, 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 두고 배포해요.
5. 나온 **웹 앱 URL**(…/exec 로 끝나요)을 복사해요.
6. GitHub 의 mybase 저장소 **Settings → Secrets and variables → Actions** 에서 Repository secret 두 개를 만들어요.
   - `DRIVE_URL`: 5번의 웹 앱 URL
   - `DRIVE_KEY`: 2번의 KEY 와 똑같은 값
7. **Actions** 탭에서 마지막 실행을 열고 **Re-run all jobs** 를 눌러요. 1~2분 뒤 사이트에 반영돼요.
8. 드라이브의 `MY BASE` 폴더 안 `MY BASE 읽기 기록` 폴더를 Claude 에 연결된 구글 계정과 **뷰어**로 공유해요.
   아침 작업이 이 폴더만 읽어서 단어장에 반영해요. 메모·할 일·일정이 든 `기록` 폴더는 공유하지 않아요.

코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 바뀌어요. URL 은 그대로예요.
